# Employee Management App

## Project Overview
This is a simple web application for managing employees. Users can add, view, edit, and delete employee information. The application features form validation, a clean and responsive UI, and basic toast notifications for actions like adding, editing, or deleting employees.

## Technologies Used
- **Frontend**: React.js
- **Backend**: Node.js + Express.js
- **Deployment**: Render (Backend)
- **Styling**: TailwindCSS, Material UI and framer-motion

## Features
- **Add / Edit / Delete Employees**: Fully functional CRUD operations for managing employees.
- **Form Validation**: Ensures that the name and email are provided and that the email is in a valid format.
- **Toast Notifications**: Success and error messages displayed after each action.
- **Mobile Responsive**: The app is designed to work well on both desktop and mobile devices.
- **Hover Effects & UI Polish**: Basic hover effects and UI improvements for a better user experience.
